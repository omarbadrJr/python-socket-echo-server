2. Edge cases (separate server run, not part of lab1.pcap)

Client output:

Enter a message: anetwork
Reply: anetwork
Enter a message: Cnetwork
Reply: eknortw
Enter a message: CnEtWork
Reply: EWknort

Server output:

Server is running on port 5050
('127.0.0.1', 59203): anetwork -> anetwork
('127.0.0.1', 59211): Cnetwork -> eknortw
('127.0.0.1', 59219): CnEtWork -> EWknort

Observations:
- "anetwork": a lowercase first letter is not one of A, C, D, so the message
  is returned unchanged (rule f).
- "CnEtWork" -> "EWknort": the server sorts by character code, so uppercase
  letters come before lowercase letters.
- Empty message (just pressing Enter): the client sends zero bytes and then
  waits in recv() for a reply, while the server waits in recv() for data.
  Both block. After pressing Ctrl+C in the client, its socket closes, the
  server's recv() returns an empty string, and the server crashes:

    File "echo_server.py", line 8, in transform
      command = message[0]
    IndexError: string index out of range

  Known limitation: empty input is not handled, and the server stops
  because the error is not caught.
